# oscaryarbrough.com

This repository contains the source code for my personal website, **oscaryarbrough.com**, built using **Flask (Python)** and deployed via **Render**.

The site serves as a central hub for my work in economics, data analytics, and music — including projects, bands, and professional updates.

---

## 🚀 Tech Stack

- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS, JavaScript (Jinja templating)  
- **Deployment:** Render  
- **Version Control:** Git & GitHub  

---

## 🌐 Features

- Modular Flask application structure  
- Dynamic routing with Jinja templates  
- Responsive layout for desktop and mobile  
- Sections highlighting:
  - Music projects & bands
  - Data & economics work
  - Personal and professional information  

---

## 🧠 Motivation

I built this site from scratch to deepen my understanding of:
- Web development with Python
- Deployment workflows
- Maintaining a clean, scalable codebase

It also functions as a living portfolio that evolves alongside my academic and creative work.
